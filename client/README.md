# Unity Client Directory
This folder is reserved for the Unity 6 LTS client project.

## Scaffolding Instructions for Claude Code (Senior Engineer)
1. Initialize the Unity Project (2D/3D Core depending on design) in this folder.
2. Install the required packages via Package Manager:
   - Colyseus Unity SDK
   - UniTask
   - VContainer
   - DOTween
   - Unity Localization
   - Firebase Unity SDK (Auth, Analytics, Crashlytics)
3. Set up the foundational folder structure:
   - `Assets/Scripts/` (Core logic, Network, UI)
   - `Assets/Prefabs/`
   - `Assets/Scenes/` (Boot, Lobby, Game)
   - `Assets/Art/` (UI, Sprites, Models)
   - `Assets/Audio/`
