# design/

Source design assets and specifications for the premium UI system described in
the project blueprint:

- Figma exports and screen flows (Lobby, Matchmaking, Board, Shop, Profile).
- Design tokens: colour ramps, gradients, elevation, blur radii.
- Theme specifications: Glassmorphism, Neumorphism, Material 3, dark and light.
- Typography specimens: Inter, Poppins, SF Pro, Nunito.

Exported, runtime-ready art belongs in `assets/` (and ultimately under
`client/Assets/`); this folder holds the design sources they are cut from.
